# 旋转指示器

<!-- preview spinner 120 -->

`ui.Spinner` 用旋转动画表示进度不确定的任务正在进行，类似 AppKit 的旋转进度指示器：旋转的辐条使用主题中的次要文字颜色，整体高度略大于主题字号。

```go
ui.Row(c).Gap(8).Children(func() {
	ui.Spinner(c).Label("Loading")
	ui.Text(c, "Loading messages…")
})
```

`Size` 可以让它更大，例如在空视图中使用 `Size(32, 32)`。即使系统设置了减少动效，它仍会继续转动，如同系统的旋转指示器：它表明仍有事情在进行。

它只在可见时转动，开销仅来自绘制：辐条每转一圈更新十二次，每次窗口都只重绘上一帧，不重新运行视图函数。

## 辅助功能

辅助技术会将其识别为进度不确定的进度指示器，名称由 `Label` 指定。
