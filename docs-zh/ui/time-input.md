# 时间输入

<!-- preview time-input 120 -->

`ui.TimeInput` 创建时间输入框，显示 `*time.Time` 的时刻，采用用户区域格式（`Context.Region`）的小时制：15:04 或 3:04 PM。小时、分钟和上下午各自可获得键盘焦点，类似 AppKit 日期选择器的分段：Up 和 Down 循环增减当前分段的值；键入数字可设置当前分段，小时输入完成后自动转到分钟；输入 AM 或 PM 的首字母（或当前语言对应名称的首字母）可选择上下午；Left 和 Right 在分段之间移动焦点。上下午的名称及位置取决于窗口语言：中文显示为“下午3:04”，上下午在前。`Changed` 报告新时间，保留原值的日期和时区。

```go
ui.TimeInput(c, &app.alarm).Label("Alarm")
```

单击小时或分钟会让它获得焦点。与[日期输入](date-input.md)一起使用时，两者编辑同一个 `time.Time`。

## 辅助功能

辅助技术看到几个微调按钮，名称由输入框的 `Label` 和窗口语言中的“小时”“分钟”“上下午”组成。
