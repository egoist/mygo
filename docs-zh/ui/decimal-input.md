# 小数输入

<!-- preview decimal-input 160 -->

`ui.DecimalInput` 是用于金额的[数字输入](number-input.md)：它编辑一个 `*string`，其中保存两个边界之间的精确小数，Up 和 Down 以及它旁边的按钮按步长改变它。值按与步长完全相同的小数位数写出，如 `"1234.50"`；边界也这样写，`""` 表示没有限制。内部用 `math/big` 整数以步长最后一位小数的单位计数，因此任何金额都不会以二进制浮点数保存。

```go
ui.Field(c, "Amount", func() {
	if ui.DecimalInput(c, &app.amount, "0", "", "0.01").Changed() {
		app.save()
	}
})
```

输入的内容一旦成为范围内的数字就立即生效，小数前用 `.`，每三位数字之间用 `,`，并可选一个 `-`：`1,234.5` 会设置 `"1234.50"`，失去焦点后便按这种方式显示。`*string` 中的文本和金额可以转换成应用使用的任何小数类型（`shopspring/decimal`、`apd`、`big.Rat`），也适用于数据库的 TEXT 列。

## 什么都不舍入

步长为 `0.01` 时，`1.500` 是 `1.50`，但 `1.005` 不是该输入接受的数字：它不会对其舍入，而是保持原值，并用 `Error` 标记输入；环绕它的[字段](form.md)会在下方显示该错误消息，直到文本被改正。不是数字或超出范围的文本也会这样标记，并在输入失去焦点后保留，因此笔误绝不会被悄悄替换。清空输入会让值保持原样，失去焦点后再重新显示它。

应用设置的值会替换已输入的内容，错误也不例外。应用设置的值若小数位多于步长，或超出范围，会按原样显示并带标记。`Changed` 报告新值；以另一种方式写出的值（例如用 `1.5` 表示 `1.50`）不算。

与 `NumberInput` 一样，它在窗口显示的每种语言中都以相同方式读取 `.` 和 `,`：`1,50` 不是一点五，而是一段并非数字的文本，输入会标记它，而不会把它读作 150。

## 辅助功能

辅助技术看到一个显示该值的微调按钮（spin button），由它的 `Label` 或它所在的字段命名，可按步长递增和递减，并会按输入的文本精确朗读该值。错误消息会描述该输入，它会把输入读作无效。
