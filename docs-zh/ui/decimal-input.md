# 小数输入

<!-- preview decimal-input 160 -->

`ui.DecimalInput` 是用于金额的[数字输入](number-input.md)：用 `*string` 保存指定范围内的精确小数，按 Up、Down 或旁边的按钮可按步长增减。值的小数位数与步长相同，例如 `"1234.50"`；上下限也采用相同写法，`""` 表示不限制。内部用 `math/big` 整数计数，单位取步长最末一位小数的位值，因此金额不会以二进制浮点数保存。

```go
ui.Field(c, "Amount", func() {
	if ui.DecimalInput(c, &app.amount, "0", "", "0.01").Changed() {
		app.save()
	}
})
```

输入内容只要是范围内的有效数字，就会立即更新值。小数点用 `.`，千位分隔符用 `,`，也可带负号 `-`：输入 `1,234.5` 会将值设为 `"1234.50"`，失去焦点后显示为后者。`*string` 保存的金额可转换为应用使用的小数类型（`shopspring/decimal`、`apd`、`big.Rat`），也可存入数据库的 TEXT 列。

## 什么都不舍入

步长为 `0.01` 时，`1.500` 是 `1.50`，但 `1.005` 不是该输入接受的数字：它不会对其舍入，而是保持原值，并用 `Error` 标记输入；包裹它的[字段](form.md)会在下方显示该错误消息，直到文本被改正。不是数字或超出范围的文本也会这样标记，并在输入失去焦点后保留，因此笔误绝不会被悄悄替换。清空输入会让值保持原样，失去焦点后再重新显示它。

应用设置值时，会替换当前输入的内容，包括错误内容。如果设置的值小数位数多于步长，或超出范围，则按原样显示并标记错误。`Changed` 只报告数值变化；仅写法不同（例如用 `1.5` 表示 `1.50`）不算变化。

与 `NumberInput` 一样，它在窗口显示的每种语言中都以相同方式读取 `.` 和 `,`：`1,50` 不是一点五，而是一段并非数字的文本，输入会标记它，而不会把它读作 150。

## 辅助功能

辅助技术看到一个显示该值的微调按钮（spin button），由它的 `Label` 或它所在的字段命名，可按步长递增和递减，并会按输入的文本精确朗读该值。错误消息会描述该输入，它会把输入读作无效。
