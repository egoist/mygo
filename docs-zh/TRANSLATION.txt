MyGo 文档的中文翻译：译者须知
================================

This directory holds the Simplified Chinese of ../docs, page for page.
(architecture.md is not translated: /zh/docs/architecture renders the English
page, as any page without a translation here does.) The
website serves it under /zh/docs; a page without a translation falls back to
English, so a missing file is not an error. Do not change this file.

Rules
-----

- Translate into Simplified Chinese (简体中文), technical and concise, in the
  register of the English docs: direct, plain, no marketing. Address the reader
  as 你, never 您. Use Chinese punctuation (，。：；！？、“”‘’（）——……), with a
  space between Chinese text and inline code, Latin words and numbers, as in
  `ui` 包, Go 1.24.
- Keep the structure of the page: the same headings, paragraphs, list items,
  tables, blockquotes, links and code blocks, in the same order. Do not add,
  merge, split or drop sections, examples or sentences. Do not add summaries,
  notes or translator remarks.
- `#` at the top is the page's title: translate it like the rest, and make it
  the same as the page's title in the README's list of pages.
- Code blocks (```) and their content are byte for byte the English, comments
  included: users compare them with the code. Inline code is unchanged too.
  The number of fences and their info strings must match the source.
- Links: translate their text, keep their URL. A link to another page of the
  docs keeps its file name (`bindings.md`, `plugins/fetch.md`). If you wrote
  the target page in this batch, make its anchor (`#the-anchor`) the GitHub
  slug of the translated heading: lowercase, spaces to hyphens, punctuation
  dropped. Otherwise keep the English anchor.
- Keep raw HTML and comments exactly: `<!-- preview name 140 -->`,
  `<!-- app name 480 -->`, `<!-- repository-only:start/end -->`, `<img>`,
  `<picture>`, `<source>`, `<br>`. Translate only their visible text and alt
  text.
- Do not translate: identifiers, API names, types, methods, fields, files,
  directories, commands, flags, environment variables, versions, URLs, and
  the names of products: MyGo, Go, cgo, IPC, WKWebView, WebKitGTK, WebView2,
  GPU, Metal, Direct3D, OpenGL, macOS, Linux, Windows, GitHub, Xcode, Swift,
  Rust, Zig, Bun, npm, Shiki, GTK, AppKit, TCC, CLDR, ICU, JSON, YAML, SQLite.
  `ui.Button`, `app.Run`, `mygo.json`, `MYGO_AUTOMATION` stay as they are.
- Keep the English of a term in parentheses the first time where the code uses
  it and the translation could be mistaken, such as 绑定（binding）; elsewhere
  translate plainly.

Style of the prose
------------------

Write Chinese that reads as if it had been written in Chinese, not a
word-for-word rendering of the English: split long English sentences, move
the subject and the time to where Chinese puts them, and drop pronouns the
sentence does not need. Technical, direct, no marketing.

Prose terms are translated, never left in English without a reason: release
发布版本, artifact 产物, build 构建, upload 上传, feature 功能, default 默认值,
call 调用, return 返回. A name the code uses is written as code: "没有 `updates`
配置时", not "没有 updates 时"; "`-upload` 无处可传". Keep such names in
backticks so they read as identifiers rather than untranslated words.

Avoid 的的, a second 时 in one clause, and "在没有…时" piled up: "没有发布版本
时，`-upload` 无处可传" is enough.

A page's title in the navigation comes from the README's lists
(`- [Title](page.md): what it covers`): translate the title and the
description, keep the list and the link.
