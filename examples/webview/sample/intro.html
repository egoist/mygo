ui.WebView

A system web view embedded in a MyGo-drawn window

This page is rendered by a real web engine, inside the window, beside the native file list on the left. MyGo draws the list; the platform draws this page, in its own view on top of the surface.

Load it with LoadHTML or LoadURL. The window's bridge is injected into the page as window.mygo, and a post to the web view's script-message handler, window.webkit.messageHandlers.mygo.postMessage(text), reaches Go through OnMessage.
