# Languages

A MyGo app says its messages in the language of the people who use it.
Its messages live in catalogs, a JSON file per language, from which
`mygo generate` writes typed functions for Go and for the pages, which
say each message in the language the app shows, with the plural forms
of that language. The whole app shows one language: its own messages,
MyGo's controls and menus, and its pages.

```json
{
  "filesSelected": "{count, plural, =0 {No files selected} one {# file selected} other {# files selected}}"
}
```

```go
status.SetText(locales.FilesSelected(len(selected))) // "3 files selected"
```

```ts
import { messages } from "./locales"; // generated

status.textContent = messages.filesSelected(selected.length);
```

## Catalogs

Turn the catalogs on in the [configuration](configuration.md#i18n):

```ts
export default defineConfig({
  i18n: { dir: "locales", source: "en" },
});
```

`dir` (default `locales`) holds a catalog per language, named after its
[BCP 47](https://www.rfc-editor.org/info/bcp47) tag: `en.json`,
`de.json`, `pt-BR.json`, `zh-Hans.json`, `zh-Hant.json`. `source`
(default `en`) is the language the app is written in: its catalog has
every message, and the others fall back to it. The languages the app
ships are the files of `dir`, which holds nothing else but Go files; an
app without catalogs ships English.

A catalog is an object of messages, as Flutter's ARB files are, whose
keys name them. The source language's also describes them, under the key
with an `@`, for the translators and the generated code:

```json
{
  "@@locale": "en",
  "filesSelected": "{count, plural, =0 {No files selected} one {# file selected} other {# files selected}}",
  "@filesSelected": {
    "description": "The status bar, while files are selected.",
    "placeholders": {
      "count": { "type": "int", "example": "3" }
    }
  },
  "greeting": "Hello, {name}!"
}
```

```json
{
  "@@locale": "de",
  "filesSelected": "{count, plural, =0 {Keine Dateien ausgewählt} one {# Datei ausgewählt} other {# Dateien ausgewählt}}",
  "greeting": "Hallo, {name}!"
}
```

A key is a letter, then letters, digits and `_`; the functions of a key
are named after it. A placeholder's `type` is `String`, `int`, `double`,
`num`, `DateTime` or `Object`, which makes the type of the functions'
parameter (`string`, `int`, `float64`, `float64`, `time.Time` and `any` in
Go; `string`, `number`, `Date` and `unknown` in TypeScript). Without one,
an argument counted by `plural`, `selectordinal` or `number` is an `int`, a
`date` or `time` argument a `DateTime`, and any other a `String`. The
parameters come in the order of `placeholders`, then of the message.
`@@locale` is optional, and must name the file's language.

## Messages

Messages are written in ICU MessageFormat, the format of ARB files, of
Android and of Format.JS:

| Message | Says |
|---|---|
| `Hello, {name}!` | the value of `name` in its place |
| `{count, plural, one {# file} other {# files}}` | the case of the plural category of `count` in the message's language; `#` is the number |
| `{count, plural, =0 {No files} one {# file} other {# files}}` | `=0` is for exactly 0, before the categories |
| `{n, plural, offset:1 =0 {Nobody} =1 {{host}} one {{host} and # other} other {{host} and # others}}` | with `offset:1`, the categories and `#` count `n - 1` |
| `{place, selectordinal, one {#st} two {#nd} few {#rd} other {#th}}` | the case of the ordinal category: 1st, 22nd, 103rd, 11th |
| `{gender, select, female {She} male {He} other {They}} replied.` | the case named after the value, else `other` |
| `{price, number}`, `{ratio, number, percent}`, `{n, number, integer}` | a number in the language's way (1,234.5; 1.234,5) |
| `{day, date, short}`, `{day, time, short}` | a date, or a time, in a style: `short`, `medium`, `long` or `full` |

Cases nest, and every `plural`, `selectordinal` and `select` has an
`other` case. A number in `{n}` is written as `{n, number}` writes it. The
plural categories are those of the [Unicode CLDR](https://cldr.unicode.org)
for the message's language: `one` and `other` in English, only `other`
in Chinese and Japanese, `one`, `few`, `many` and `other` in Russian, six in
Arabic. Write the ones the language has; `other` is required.

An apostrophe quotes the next brace, or `#` in a plural case: `'{'` says
`{`, `'{name}'` says `{name}`, and two apostrophes say one. Any other
apostrophe is just one, so `don't` needs no quoting.

## In Go

`mygo generate` writes `catalog_gen.go` into the catalogs' directory, a Go
package of its own (named after the directory, or as its other Go files
say), which embeds the catalogs:

```go
import "example.com/notes/locales"

title := locales.FilesSelected(3)                // in the language the app shows
german := locales.In("de").FilesSelected(3)      // in another
```

Each key has a function with the typed parameters of its placeholders,
which says the message in the language the app shows, and a method of
`locales.In(tag)` for another language. The package registers its catalog
with package `i18n` as it initializes, which makes the catalogs' languages
the app's: import it, with `import _ "example.com/notes/locales"` if the Go
code says no message itself. `mygo dev` and `mygo build` warn when the app
does not.

`mygo dev` writes the functions again as the catalogs change, and
`mygo build` before it compiles the app. They are generated code: commit
them with the catalogs, so that `go build` and `go test` work without the
CLI.

## In pages

Next to the [TypeScript client](bindings.md#the-generated-client),
`mygo generate` writes a module named after the catalogs' directory, such
as `src/locales.ts`, with a typed function per key:

```ts
import { languages, messages, messagesIn } from "./locales";

heading.textContent = messages.filesSelected(3); // in the language the page shows
messagesIn("de").greeting("Ada");                 // "Hallo, Ada!"
```

The module holds the messages of every language, and `mygo-runtime/i18n`
formats them with the browser's `Intl`, so the pages and Go say the same
words in the same plural forms. The messages are bundled with the
frontend rather than fetched: the first paint is in the right language,
without waiting for a request, also in a page of the dev server opened in
a browser. `messages` says each message in the language of the moment:
the app's, which MyGo gives the page before its scripts run, else the
browser's. Draw the page again when the language changes.

`formatMessage(locale, message, args)` from `mygo-runtime/i18n` formats a
message of your own.

## The language the app shows

The app shows one language, which `mygo.App.Locale()` returns: of the
languages it is written in, the one the user reads best, by the languages
they prefer in the order the system lists them
(`App.PreferredLanguages()`), as `zh-Hant` for a reader of `zh-TW`; else
the app's source language. An app written in English alone shows English
to a reader of Chinese, MyGo's controls and menus too, as AppKit does. The
languages the app is written in are its catalogs', which `App.SetLanguages`
replaces for an app without them.

`App.SetLocale("de")` shows another language at once, and keeps it for the
next launches; `App.SetLocale("")` follows the user's languages again. A
language menu:

```go
for _, tag := range mygo.App.Languages() {
	items = append(items, &mygo.MenuItem{Label: tag, Type: mygo.MenuItemRadio,
		Checked: tag == mygo.App.Locale(),
		Click:   func(*mygo.MenuItem, *mygo.Window) { mygo.App.SetLocale(tag) }})
}
```

macOS keeps the language as the app's language in System Settings
(`AppleLanguages` of the app's defaults), which AppKit and WebKit say their
own texts in from the next launch; browsers keep it in `localStorage`;
Windows and Linux in the file `locale` of `App.Path(mygo.PathUserData)`.
`App.OnLocaleChanged` hears the language change, as `SetLocale` changes it
or the user's languages do (macOS, Windows and browsers report theirs;
Linux reads the environment, `LANGUAGE`, `LC_ALL`, `LC_MESSAGES` and
`LANG`, once).

When the language changes, windows of native UI draw anew, menu items
labelled by their role say the new language's labels, pages hear the
`mygo:locale` event (`onLocaleChange` of `mygo-runtime`) and those loaded
later start in it: `mygo.locale` and `mygo.dir` are there before the
page's scripts run; `mygo.dir` is the direction native UI is laid out
in, the language's unless `MYGO_DIRECTION` says otherwise, which GTK's
own widgets, as menus, follow on Linux too. Web views take the language too: WebView2 as its
environment is made, which keeps it (a change shows from the next launch),
WebKitGTK at once, WKWebView from the next launch.

### Regional formats

How dates, times and numbers are written is a setting of its own:
`App.Region()` returns the locale of the user's formats, which may be
another language's than the one the app shows, the first day of the week
and whether times have 12 or 24 hours, with the changes the user made in
the system's settings. `App.OnRegionChanged` hears them change.

### Native UI

`ui.Context.Locale()` and `ui.Context.Region()` return the app's language
and formats; a frame follows their changes. Text is drawn in the app's
language, which picks the glyphs the system's text stack draws for it, as
the Han characters Chinese and Japanese draw apart. `Element.Lang` sets the
language of an element's text and of the elements inside it, as HTML's
`lang` does, `Span.Lang` of a span of a `RichText`, `Font.Lang` of text a
`Painter` shapes:

```go
ui.Text(c, "「直」").Lang("ja") // a Japanese quote in a Chinese app
```

Han characters in a language that does not write them, as a Chinese name
in English text, keep the glyphs the system picks for the user, as
browsers do. Browsers draw the text of native UI in the page's language,
which MyGo makes the app's.

## MyGo's own strings

MyGo's controls, its code editor and its menus say their own words: "Undo",
"Find", "Quit Notes". They come in English, Simplified Chinese and
Traditional Chinese, and say the language the app shows. An app changes
them, or gives them its other languages, with keys `mygo.<key>` in its
catalogs:

```json
{
  "mygo.undo": "Rückgängig",
  "mygo.menuQuitApp": "{app} beenden"
}
```

The keys, their messages and their arguments are MyGo's catalog,
[internal/l10n/en.json](https://github.com/egoist/mygo/blob/main/internal/l10n/en.json).
A string resolves as the app's own do: in the app's language, then the
languages it falls back to, then the app's source language, then English.
`mygo.appName` and `mygo.appDescription` are the app's name and
description in a language, which packaging writes where systems list the
app (see [building and distributing](distribution.md#languages)).

## Which message

A message is the one of the catalog's language that suits the language
asked for best: `zh-Hant` for `zh-TW`, `pt-PT` for `pt-AO`, `en-GB` for
`en-AU`. When that language lacks it, it falls back along CLDR's parent
locales (`en-AU`, `en-001`, `en`; `zh-Hant-HK`, `zh-Hant`), then to the
source language: a missing translation says the source's message rather
than nothing. Its plural cases follow the rules of the language the
message is written in; numbers and dates, the conventions of the language
asked for.

## Checking the catalogs

`mygo generate` and `mygo build` check the catalogs, and so does
`mygo i18n check`. Errors stop them:

- a file not named after a canonical tag, or whose `@@locale` differs;
- a message that does not parse;
- a key a translation has and the source does not, or a key `mygo.<key>`
  MyGo has no message for;
- an argument a translation has and the source's message does not, or used
  in a way its type cannot be (a `String` counted by `plural`);
- two keys whose functions would have the same name.

Warnings do not: messages a translation lacks, which say the source
language's; arguments it leaves out; plural cases its language does not
have (`few` in English) or lacks (`few` in Russian, which says `other` in
its place); placeholders a message does not use.

## Trying a language

`mygo dev -lang de` runs the app in German without changing the language
it keeps. Two pseudo locales test layouts before any translation exists,
as Android's do:

- `en-XA` accents the letters of the source language's messages, makes them
  a third longer and brackets them, `[Šéļéçţ ƒîļéš one two]`: text that
  stays plain is not in a catalog, cut text is too short a space, and a
  sentence of several brackets is made of pieces a translation cannot
  reorder.
- `ar-XB` shows each word right to left, and lays the app out right to
  left: what does not mirror shows.

## Package i18n

The generated code is built on package
[`i18n`](https://pkg.go.dev/github.com/egoist/mygo/i18n), which apps can
use directly: `NewCatalog` reads catalogs from any `fs.FS`, `ParseMessage`
and `Message.Format` format a message, `PluralCategory` and
`OrdinalCategory` give the CLDR plural category of a number, written as an
integer, a float or a decimal string whose fraction digits count (`"1.50"`
has two), and `Parent` the locale a locale falls back to. Its data comes
from CLDR `i18n.CLDRVersion`.

The CLDR data is generated: `go generate ./i18n` reads the pinned release

are generated by `go generate ./internal/l10n`.
